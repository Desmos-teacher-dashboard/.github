## About Desmos

Desmos is a graphing calculator built for teaching. It turns equations into visible graphs, so students can explore math instead of only reading it. For teachers, Desmos adds a dashboard that shows what every student is doing during a lesson.

Desmos keeps the focus on math. A teacher can open the graphing calculator, build a set of graphs, and share them with a class. The teacher dashboard then shows each student's screen, so help arrives before a learner falls behind. Desmos classroom activities hold the whole lesson together, from a warm-up graph to a short exit check.

Desmos also works well for planning. A teacher can prepare a Desmos math lesson, save it, and reuse it with another group. Graphs stay editable, so adjusting an example takes seconds. During class, Desmos student progress updates as learners work, which makes it easy to spot who needs a hint and who is ready for a harder task.

The same tool serves students at home. They open the Desmos graphing calculator, plot their own equations, and check their thinking before class. Teachers see that work through the dashboard when a lesson is running.

Desmos fits everyday classroom hardware. A laptop, a tablet, or a school computer can run the calculator, and the teacher dashboard stays readable on a projector. Nothing about Desmos feels heavy, which matters when a lesson has to start on time.

## Getting Started with Desmos

1. **Open Desmos** – Launch the Desmos graphing calculator and confirm the display settings.
2. **Build a graph** – Enter a simple equation so the class sees how Desmos draws it.
3. **Create an activity** – Turn the graph into a short Desmos classroom activity with one question.
4. **Share with the class** – Give students the link and open the Desmos teacher dashboard.
5. **Watch progress** – Use Desmos student progress to see who is ready for the next step.
6. **Save the lesson** – Store the Desmos math lesson so it can be reused with another group.
